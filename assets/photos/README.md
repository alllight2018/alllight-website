# 写真の置き場所（この5枚を入れてください）

このフォルダに、いただいた写真を**下記のファイル名で保存**するだけで、サイトに自動反映されます。
（GitHubのこのフォルダで「Add file → Upload files」からドラッグ&ドロップでOK）

| ファイル名 | どの写真か | 使われる場所 | 推奨 |
|---|---|---|---|
| `building-night.jpg` | 夜景の新しい公共建築（バスロータリーの建物） | トップ／実績ページのヒーロー背景 | 横長・長辺1600px以上 |
| `genba.jpg` | 若手男性が単管に電動工具で作業している現場写真 | 採用ページのヒーロー背景＋「電気工事士」インタビュー | 横長・1200px以上 |
| `sekou-kanri.jpg` | メガネの男性が図面をPCで確認している写真 | 採用「施工管理」インタビュー | 横長・900px以上 |
| `staff-jimu.jpg` | 女性が事務デスクで作業している写真 | 採用「積算・入札／事務」インタビュー | 横長・900px以上 |
| `daihyo.jpg` | ロゴ入り白ポロの笑顔の男性（PC） | 会社案内の「代表メッセージ」写真 | 横長・900px以上 |

## 注意
- **`daihyo.jpg`** は「代表メッセージ」欄（代表取締役 名里 雄太）に表示します。
  もしこの写真が代表ご本人でない場合は、別の枠（採用インタビュー等）へ移しますのでお知らせください。
- 縦横比は自動でトリミング（cover）されます。人物が中央に来る写真だときれいに収まります。
- ファイルを入れるまでは、該当箇所はグレー／暗いプレースホルダで表示されます（レイアウトは崩れません）。
- Instagram連携（トップ・採用の投稿枠）は `data/instagram.json`＋Graph APIトークンで別途自動更新されます。
