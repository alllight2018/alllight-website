# 会議自動化システム 設計書 —「Meetを開くだけで、すべてが完結する」

株式会社オールライトの会議運営を、**「Meetを開く → 話す → 自動で記録・引き継ぎ・資産化・改善提案まで回る」** 一本の流れに再設計したものです。
このフォルダには、その設計書（本ファイル）と、実装（Google Apps Script）が入っています。

---

## 1. 目指す姿

```
   ┌──────────┐   話すだけ    ┌──────────────┐
   │  Meetを開く │ ───────────▶ │ Gemini が自動でメモ │
   └──────────┘              └───────┬──────┘
                                        │ メモがGmailに届く
                                        ▼
                               ┌──────────────┐
                               │ 本システム(Apps Script) │
                               └───┬───────┬────┘
              次回予定へ引き継ぎ │       │ 会社の資産として保存
                                   ▼       ▼
                    ┌────────────┐  ┌──────────────┐
                    │ 次回カレンダーの │  │ 会議ログSheet /  │
                    │ 説明文に自動反映 │  │ 会議資産ログDoc   │
                    └────────────┘  └───────┬──────┘
                                                    │ 週1回
                                                    ▼
                                        ┌──────────────┐
                                        │ 業務改善サマリーを  │
                                        │ 社長へ自動メール    │
                                        └──────────────┘
```

社員がやることは **「Meetを開いて、いつも通り話す」だけ**。あとは全部自動です。

## 2. 現状診断 —「最近うまくいかない」の原因

Gmail・カレンダーを実際に点検して特定した原因は次の4つです。

| # | 原因 | 具体例 | 対策 |
|---|------|--------|------|
| 1 | **Geminiのメモ生成そのものが失敗** | 「サポートされている言語での会話量が不足」で、施行管理部会8/7・入札会議8/4・施行管理勉強会8/7が取得失敗（`meetings-noreply@google.com`から「メモに関する問題」通知） | 失敗通知も取り込み、**次回冒頭で口頭回収する指示**を自動で説明文に入れる（穴を塞ぐ）＋ 会議冒頭チェック手順を台本に固定 |
| 2 | **会議名の表記ゆれで突き合わせが外れる** | カレンダー「工事部 **朝礼**MTG」↔ Geminiメモ「工事部 **朝**MTG」／「**施行**管理部会」↔「**施工**管理部会」／全角・半角スペース混在 | `Config.gs` の `aliases` で吸収し、スペース・記号を除去して照合（`normalizeName_`） |
| 3 | **テンプレートがバラバラ** | 施行管理部会が「ダッシュボードのみ版」と「台本フル版」で混在、幹部会議は**定例が2系列に重複** | 台本を `Templates.gs` の**唯一の正本**から毎回再生成。幹部会議は2系列を両方見て「次回が近い方」に反映 |
| 4 | **全体朝礼がまだLINE通話** | 8:08 / 9:00 の朝礼がカレンダーに無く、資産パイプラインに未接続 | Meet固定リンクの定例を作成し、同じパイプラインへ接続（`createMorningAssemblies`） |

> ※ 現在の自動化は**動いてはいます**（8/20 施行管理部会の説明文に「8/7は取得失敗→冒頭で回収」という引き継ぎが実際に入っていました）。本設計はそれを「失敗に強く・ブレない」形に作り直すものです。

## 4. 実装ファイル（`automation/gas/`）

| ファイル | 役割 |
|---------|------|
| `Config.gs` | 会議レジストリ（正本）。会議名・別名・Meet・司会ローテ・定例ID |
| `Templates.gs` | 会議ごとの司会進行台本（正本）と差し込み処理 |
| `Notes.gs` | Gmailから Geminiメモ／失敗通知を収集・構造化（冪等：処理済みラベル） |
| `CalendarSync.gs` | 次回定例を特定し、説明文（台本＋引き継ぎ）を書き込む |
| `Assets.gs` | 会議ログSheet・会議資産ログDocへ蓄積（会社の資産化） |
| `Improve.gs` | 週次で業務改善サマリーを社長へメール |
| `Llm.gs` | （任意）Geminiで要約品質を強化。キー無しでも動作 |
| `Main.gs` | 入口・トリガー設置・朝礼定例の作成・自己診断 |
| `appsscript.json` | 権限とタイムゾーン・拡張サービス設定 |

なぜ Google Apps Script か：Gmail・カレンダー・Docs・Sheetを**追加の認証情報なし**で、社長アカウントの権限でそのまま操作でき、時間トリガーで無人運転できるためです（＝現在の「GoogleのAPIで自動」の正統な置き場所）。ロジックは同じなので、将来GitHub ActionsやSupabaseへ移すことも可能です。

## 5. 導入手順（初回のみ・15分）

1. <https://script.google.com> で新規プロジェクトを作成（社長アカウントで）。
2. `automation/gas/` の各 `.gs` と `appsscript.json` を貼り付け（マニフェストは「プロジェクトの設定 → appsscript.json をエディタで表示」をONに）。
3. 左「サービス ＋」→ **Calendar API** を追加（識別子 `Calendar`）。
4. 関数 **`setupAssets`** を実行 → 「会議ログ」Sheetと「会議資産ログ」Docが自動生成（実行ログにURL）。
5. 関数 **`installTriggers`** を実行 → 15分毎の取り込み＆週次改善レポートが動き出す。
6. （任意）**`diagnose`** を実行 → 各会議の「次回予定」が正しく拾えているかログで確認。
7. （任意・品質UP）`Google AI Studio` でAPIキーを取得し、プロジェクト設定 → スクリプトのプロパティに `GEMINI_API_KEY` を登録。

## 6. 全体朝礼(8:08 / 9:00)のMeet化

LINEグループ通話を、**固定Meetリンクの定例**に置き換えます。

**作り方（自動）**：`Main.gs` の `createMorningAssemblies()` の `ATTENDEES` に参加者メールを書いて実行すると、
- 平日くり返しの「全体朝礼 8:08」「全体朝礼 9:00」を作成
- 各定例に**固定Meetリンク**を発行
- 説明文に朝礼テンプレ（開始時の「Geminiメモを取る」手順つき）をセット

以降は **同じMeetリンクを毎朝開くだけ**。Geminiメモが自動生成され、届いたメモは本システムが「朝礼」資産へ集約します。

**現場で確実にメモを残すコツ**（原因#1を減らす）：
- 開始時に必ず **アクティビティ →「メモを取る」（言語：日本語）** を押す（司会 or 最初の1人の役割として台本に固定済み）
- できれば録音もON
- 30秒以上、日本語で発話する（短すぎると「会話量不足」で失敗する）

将来的には、開始忘れを防ぐため「Meet入室＝メモ自動開始」を管理者設定（Google Workspace管理コンソール）で既定化することを推奨します。

## 7. 会社の資産化と業務改善ループ

- **会議ログ Sheet**：全会議の索引（日付／会議／記録OK・失敗／要点／次アクション／決定事項／メモDocリンク）。
- **会議資産ログ Doc**：要約と全文リンクを時系列で蓄積。「会話をすべて残す」器。
- **週次改善サマリー**：毎週月曜8:00、直近7日のログから「決定事項・繰り返す問題・改善提案3つ・来週のフォロー」を社長へ自動メール（`GEMINI_API_KEY`があれば提案つき、無ければ集計サマリー）。

これで「会議 → 記録 → 資産 → 改善」が人手なしで一周し、改善事項が毎週見える形で戻ってきます。

## 8. よくある質問

- **Q. メモが英語判定で失敗したら？** → 失敗通知も取り込み、次回説明文に「冒頭で個人目標を口頭回収」を自動挿入。抜け漏れになりません。
- **Q. 会議の時間や司会を変えたい** → `Config.gs` を編集するだけ。台本は `Templates.gs`。
- **Q. LLMは必須？** → いいえ。未設定でも全機能動きます。設定すると要約と改善提案の質が上がります。
- **Q. 既存のApps Scriptと二重にならない？** → 導入時に旧トリガーを停止してください（本システムの `installTriggers` は本システム分のみ管理）。
